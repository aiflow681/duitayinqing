[游戏名称]  叠叠乐大师 - Tower Stacker

[游戏介绍]一款极简、纯原生 JavaScript + Canvas 实现的经典堆叠类休闲小游戏。  
玩家通过精准的时机点击（或触摸），将不断左右摇摆的木块准确落在上一层上，挑战能堆多高！  
越往上越难，考验反应、预判与手感～



## 游戏特色

- **极致轻量**：0 依赖，单文件 HTML（~400 行核心逻辑），打开即玩
- **流畅手感**：丝滑的正弦摇摆 + 平滑相机跟随 + 弹性按钮反馈
- **视觉质感**：圆角木块 + 顶部高光 + 底部阴影 + 天空渐变 + 漂浮云朵视差
- **难度递增**：层数越高，木块摆动速度越快，容错空间越小
- **响应式适配**：支持桌面点击 & 移动端触摸，防缩放优化
- **本地存档**：最高层数自动保存在 localStorage

[玩法说明]

不断有木块从屏幕上方左右**来回摇摆**，  
**点击屏幕任意位置**（或触摸） → 木块立刻**垂直下落**，  
尽量让它**完美对齐**上一块，成功则保留重叠部分宽度，继续下一块；  
重叠太少（<10px）或完全错开 → 游戏结束！

| 目标       | 说明                         | 判定标准         |
|------------|------------------------------|------------------|
| 成功放置   | 重叠宽度 > 10px              | 保留重叠宽度，继续 |
| 完美放置   | 重叠几乎 100%（视觉上很整齐）| 获得完整宽度     |
| 失败       | 重叠 ≤ 10px 或完全错开       | 直接 GAME OVER   |

核心目标：**尽可能堆出更高的层数，打破自己的历史纪录！**

## 操作方式

- **桌面端**：鼠标左键单击屏幕任意位置  
- **移动端**：手指轻触屏幕任意位置  
（无虚拟按钮设计，保持极简 & 全屏沉浸感）

[技术介绍]

- **渲染**：HTML5 Canvas 2D Context
- **语言**：纯原生 JavaScript（ES6+）
- **架构**：单文件、状态机 + 游戏循环（requestAnimationFrame）
- **无任何外部依赖**：无需 npm、webpack、Three.js 等
- **主要特性实现**：
  - 正弦函数控制木块水平摇摆（速度随层数递增）
  - 木块重叠宽度精确计算与切割逻辑
  - 相机平滑跟随（Lerp 阻尼）
  - 背景渐变 + 简单云朵视差滚动
  - 圆角矩形 + 高光/阴影提升立体感
  - localStorage 记录历史最高分
  - 响应式布局 + 移动端触摸优化
