# 【游戏名称】
堆塔游戏

# 【游戏介绍】
这是一款使用Cocos Creator 3.8引擎开发的2D休闲益智小游戏。游戏中，你需要不断堆叠移动的方块，建造一座高耸入云的塔！每一层都需要精准对齐，未对齐的部分会被切除，考验你的时机把握能力，看看你能堆到多高！

# 【玩法说明】
游戏中方块会自动左右移动，你要做的就是选择合适的时机点击屏幕，让方块精准落下。

**道具机制：**
路上会不断刷新出新的方块层。
1. 精准对齐，能让塔稳固增高，得分上涨。
2. 偏移对齐，会让多余部分被切除，方块变窄，难度增加。

**操作：**
你可以通过点击屏幕，停止当前方块的移动并落下。
也可以通过观察节奏，把握最佳落点时机。

**目标：**
方块完全错过底座就会游戏结束了，不要让方块掉下去！

Tips：游戏结束会记录你的最高分数。点击重玩，刷新你的堆塔最高记录！

# 【技术介绍】
Cocos Creator 3.8引擎开发，主要语言是TypeScript，使用了Prefab预制体系统，Tween动画，UI适配方案等技术。
