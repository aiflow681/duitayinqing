【游戏名称】 堆塔游戏

【游戏介绍】 这是一款基于 Unity 引擎开发的休闲益智小游戏（Unity WebGL）。游戏中，你需要看准时机放下方块，将方块尽可能高地堆叠起来，挑战最高分数。

【玩法说明】 游戏中玩家需要观察上方不断摆动的方块，在合适的时机点击屏幕使其落下，稳稳地落在下方的方块上，持续完成高塔的堆叠。

道具： 本版本以基础物理堆叠玩法为主，常见游戏元素包含摆动方块、已放置方块、绳索与挂钩（具体以游戏内实际显示为准）。

1. 摆动方块： 游戏上方会有一个不断左右摆动的方块，作为当前回合的堆叠目标。
2. 基础底座： 游戏开始时的初始平台，作为堆塔的起点。
3. 完美堆叠： 如果方块精准对齐落下（误差极小），会获得额外加分，连续完美堆叠分数会递增。
4. 生命值： 初始拥有 3 点生命值。如果方块没有落在下方方块上而掉落，会扣除 1 点生命值。生命值耗尽则游戏结束。
5. 动态视角： 随着塔越堆越高，游戏视角会自动向上移动，保持顶部方块和摆动挂钩始终在视野内的合适位置。

操作： 你可以通过鼠标点击屏幕（PC 端）、按下空格键，或手指触控点击（移动端）来放下方块。游戏支持浏览器内交互体验，并配有移动端专属的控制按钮。

目标： 在生命值耗尽前，尽可能多地堆叠方块，保持重心稳定，挑战更高的分数。

Tips： 把握好方块摆动的节奏与速度；尽量追求完美对齐以获得高分并保持塔身平稳；遇到高塔时不要急躁，看准中心点再下手。

【技术介绍】 使用基于 Unity 引擎开发的 H5 游戏，构建平台为 WebGL。项目入口为 index.html，运行时通过 Unity Loader 加载游戏框架与资源配置，支持自适应屏幕尺寸，兼容 PC 和移动端浏览器。
